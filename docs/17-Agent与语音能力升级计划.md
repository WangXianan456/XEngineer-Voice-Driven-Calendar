# Agent 与语音能力升级计划

## 当前实现基线

当前系统采用前端本地闭环：

```text
Web Speech API 语音转文字
-> 本地规则解析器识别意图和时间
-> 展示结构化确认卡片
-> 用户确认后写入 localStorage
-> SpeechSynthesis 语音播报
```

核心代码：

- 意图识别和中文时间解析：`src/agent/commandParser.ts`
- 语音识别：`src/speech/useSpeechRecognition.ts`
- 语音播报：`src/speech/synthesis.ts`
- 确认状态机和 UI：`src/App.tsx`

当前支持意图：

- `create_event`：新增日程
- `list_events`：查询日程
- `delete_event`：删除日程
- `update_event`：修改日程
- `find_free_time`：查询空闲时间
- `unknown`：无法识别

## 升级目标

升级的目标不是让 AI 直接操作日历，而是让 Agent 更稳、更像真实助手：

- 覆盖更多中文口语表达。
- 支持上下文指代和多轮修正。
- 多候选时让用户选择，不默认误删或误改。
- 语音识别失败时有清晰降级路径。
- LLM 和云端语音只作为增强能力，不破坏本地可演示闭环。

## 阶段 A：增强本地规则和测试

优先级：P0

要做：

- 扩充中文口语模板：
  - “帮我约个会”
  - “明早九点提醒我”
  - “把明天那个会取消”
  - “下周一到周三有什么安排”
  - “后天下午有没有空”
- 扩展时间解析：
  - “早一点”
  - “晚一点”
  - “上午十点一刻”
  - “下午三点到四点半”
  - “下周工作日”
- 增加解析器测试样例，覆盖新增模板。

验收：

- 不接任何外部服务也能稳定通过核心演示。
- `npm run test -- --run` 覆盖新增语料。

## 阶段 B：上下文和多候选选择

优先级：P0

要做：

- 保存最近一次被提到的事件。
- 支持指代：
  - “把它改到四点”
  - “删除刚才那个”
  - “提前十分钟提醒”
- 修改和删除匹配到多个候选时，不直接取第一个。
- 确认卡片展示候选列表，支持用户选择“第一个 / 第二个 / 取消”。

验收：

- 多个同名日程不会误删。
- “它 / 那个 / 刚才那个”能指向最近上下文。
- 高风险操作仍然必须二次确认。

## 阶段 C：LLM JSON 解析兜底

优先级：P1

要做：

- 本地规则解析失败或置信度低时，调用 LLM 解析。
- LLM 只返回严格 JSON，不直接执行写入。
- JSON 结果进入现有确认卡片。
- 增加超时、失败和无 API Key 的降级路径。

建议输出格式：

```json
{
  "intent": "create_event",
  "title": "产品评审会",
  "start": "2026-06-01T15:00:00+08:00",
  "end": "2026-06-01T16:00:00+08:00",
  "reminderMinutes": 10,
  "confidence": 0.88,
  "needsConfirmation": true
}
```

验收：

- 本地规则覆盖不了的复杂句子能被解析。
- LLM 失败时系统仍能用文字规则版演示。
- 所有写操作仍然需要用户确认。

## 阶段 D：增强语音识别能力

优先级：P1

当前 Web Speech API 的优势是接入快、无需后端；限制是浏览器兼容和中文识别质量不稳定。

要做：

- 优化 Web Speech 体验：
  - 录音中、识别中、失败、无权限状态更明确。
  - 识别结果先进入输入框，允许用户编辑后发送。
  - 支持连续识别和手动停止。
- 可选接入云端 STT：
  - OpenAI Whisper / Audio Transcriptions
  - Azure Speech
  - Google Speech-to-Text
  - 讯飞 / 腾讯云 / 阿里云语音识别
- 增加语音纠错：
  - “产品平审会” -> “产品评审会”
  - “提前十分钟题型” -> “提前十分钟提醒”

验收：

- Chrome 语音演示更稳定。
- 不支持 Web Speech 时，文字输入仍然完整可用。
- 云端 STT 失败不影响本地演示。

## 推荐实施顺序

```text
1. 扩充本地规则和测试
2. 增加上下文指代
3. 增加多候选选择
4. 接入 LLM JSON 兜底
5. 优化语音状态
6. 可选接入云端 STT
```

## 工程原则

- 本地规则是默认能力，外部 AI 是增强能力。
- LLM 不能直接写入日历。
- 删除、修改、批量操作必须确认。
- 语音失败时必须能用文字输入完成同样演示。
- 每次新增解析能力都要补测试样例。
