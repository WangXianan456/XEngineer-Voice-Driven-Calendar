# 验收测试清单

## 核心流程测试

### 添加事件

- 输入：「明天下午三点开产品评审会，提前十分钟提醒我」
- 期望：
  - 识别意图为新增事件。
  - 标题为产品评审会。
  - 时间为明天下午 3 点。
  - 提醒为提前 10 分钟。
  - 写入前展示确认。
  - 确认后日历出现事件。

### 查看事件

- 输入：「我明天有什么安排？」
- 期望：
  - 查询明天事件。
  - 对话区返回摘要。
  - 日历视图高亮或展示明天事件。

### 修改事件

- 输入：「把产品评审会改到下午四点」
- 期望：
  - 找到目标事件。
  - 展示修改前后时间。
  - 确认后更新事件。

### 删除事件

- 输入：「删除明天的产品评审会」
- 期望：
  - 找到目标事件。
  - 必须二次确认。
  - 确认后删除。
  - 支持撤销。

### 冲突检测

- 先添加：「明天下午三点到四点开产品会」
- 再添加：「明天下午三点半开设计会」
- 期望：
  - 系统提示时间冲突。
  - 用户确认后才继续添加。

### 空闲查询

- 输入：「明天下午我什么时候有空？」
- 期望：
  - 根据明天下午已有事件返回空闲时间段。

## 语音能力测试

- 首次点击麦克风时能触发浏览器权限申请。
- 录音中有明显状态提示。
- 停止说话后能把语音转成文字。
- 识别结果可编辑。
- 语音不可用时文字输入仍可使用。

## 数据持久化测试

- 添加事件后刷新页面，事件仍存在。
- 修改事件后刷新页面，修改结果仍存在。
- 删除事件后刷新页面，事件不再出现。

## 异常测试

- 输入空内容时不报错。
- 输入无法理解的内容时给出友好提示。
- 时间缺失时主动追问。
- 删除不存在的事件时提示未找到。
- 多个候选事件时要求用户选择。

## 上线前检查

- `npm run dev` 可启动。
- `npm run build` 可通过。
- 控制台无明显报错。
- Chrome 中语音识别可用。
- README 有运行方式和演示指令。
- 页面首屏能看出是语音日历工具。
