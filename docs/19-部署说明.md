# 部署说明

## 部署目标

当前主线优先部署为静态前端应用：

```text
React/Vite 静态资源
-> 浏览器语音识别
-> 本地规则解析
-> localStorage 日历数据
```

可选 FastAPI 后端只用于 DeepSeek 解析兜底和本地 Whisper ASR，不是静态部署的硬依赖。

## 本地验收部署

安装依赖：

```bash
npm install
```

开发服务：

```bash
npm run dev -- --host 127.0.0.1
```

默认访问：

```text
http://127.0.0.1:5173
```

生产构建和预览：

```bash
npm run build
npm run preview -- --host 127.0.0.1
```

预览地址：

```text
http://127.0.0.1:4173
```

## 静态平台部署

推荐平台：

- Vercel
- Netlify
- Cloudflare Pages
- 任意静态文件服务器

通用配置：

```text
Build command: npm run build
Output directory: dist
Node.js: 20 LTS 或更高
```

如果使用传统服务器，上传 `dist/` 目录即可。该应用使用前端路由很少，当前入口页面直接由 `index.html` 提供。

## 环境变量

默认演示不需要任何真实密钥。

前端可选变量：

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
VITE_SPEECH_PROVIDER=browser
```

注意：

- 不要提交 `.env`、`.env.local` 或任何真实 key。
- 生产静态站不要把 DeepSeek Key 写进前端变量。
- 只有需要后端增强解析时，才配置 `VITE_API_BASE_URL`。
- 浏览器语音识别是默认演示路径；本地 Whisper 只保留为可选开关。

## 可选后端部署

后端能力：

- `POST /api/parse-command`：DeepSeek JSON 解析兜底。
- `POST /api/asr`：本地 `faster-whisper` ASR。
- `GET /api/health`：配置健康检查。

本地启动：

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

推荐 ASR 默认配置：

```text
ASR_MODEL=base
ASR_DEVICE=cpu
ASR_COMPUTE_TYPE=int8
ASR_MAX_CONCURRENT=1
```

GPU 主机可选配置：

```text
ASR_MODEL=small
ASR_DEVICE=cuda
ASR_COMPUTE_TYPE=float16
ASR_MAX_CONCURRENT=1
```

## 上线前检查

必须通过：

```bash
npm run test
npm run eval:parser
npm run build
conda run -n base python -m unittest discover -s backend\tests -p "test_*.py"
```

浏览器演示路径：

1. 新增「明天下午三点开产品评审会，提前十分钟提醒我」。
2. 确认新增。
3. 查询「我明天有什么安排」。
4. 修改「把产品评审会改到下午四点」。
5. 新增冲突日程并取消。
6. 删除「明天的产品评审会」。
7. 撤销删除。

上线检查重点：

- 首屏不是白屏。
- 默认显示「浏览器识别」。
- 「本地 Whisper」只是可选模式。
- 文字输入兜底可用。
- 写操作必须先确认。
- 删除操作必须二次确认。
- 刷新后 localStorage 数据仍存在。
- 生产环境没有暴露 API Key。

## 回滚

静态平台优先使用平台版本回滚。

需要回滚的情况：

- 页面白屏。
- 文字输入无法发送。
- 新增、修改、删除任一核心路径不可用。
- 构建资源 404。
- 生产环境误暴露敏感配置。

如果线上不可用，现场演示直接使用本地：

```bash
npm run dev -- --host 127.0.0.1
```
