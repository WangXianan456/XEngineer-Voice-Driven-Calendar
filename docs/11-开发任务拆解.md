# 开发任务拆解

## 目标

把「语音日历 Agent」拆成可以并行开发、可以当天验收的任务，避免开发过程中范围失控。

## 任务优先级

### P0：必须完成

1. 项目初始化
   - React + Vite + TypeScript 项目。
   - 基础布局和路由。
   - 可运行、可构建。

2. 日历数据模型
   - 定义事件结构。
   - 实现新增、删除、修改、查询。
   - localStorage 持久化。

3. Agent 指令处理
   - 支持添加事件。
   - 支持查看今日、明日、本周事件。
   - 支持删除事件。
   - 支持修改事件时间。
   - 支持确认和追问。

4. 中文时间解析
   - 今天、明天、后天。
   - 上午、下午、晚上。
   - 几点、几点半。
   - 下周一到下周日。
   - 提前几分钟提醒。

5. 语音输入
   - 麦克风按钮。
   - 浏览器语音识别。
   - 失败时回退文字输入。

6. 日历界面
   - 今日事件。
   - 本周事件。
   - 简单月历或周视图。
   - 事件详情。

### P1：高分加分项

1. 语音播报
   - 添加成功播报。
   - 查询结果播报。
   - 删除前确认播报。

2. 冲突检测
   - 新事件与已有事件重叠时提醒。
   - 允许用户确认继续添加。

3. 撤销
   - 支持撤销最近一次新增、修改、删除。

4. 空闲时间查询
   - 支持「明天下午我什么时候有空」。

5. 示例指令
   - 页面展示可点击示例。
   - 一键填充演示数据。

### P2：有时间再做

1. ICS 导出。
2. LLM 复杂语义解析。
3. 移动端 PWA。
4. 第三方日历同步。

## 推荐开发顺序

1. 初始化项目。
2. 做静态 UI。
3. 做事件 CRUD 和本地存储。
4. 做文字指令 Agent。
5. 做确认状态机。
6. 接语音识别。
7. 接语音播报。
8. 加冲突检测和撤销。
9. 写测试样例。
10. 准备演示脚本和部署。

## 并行分工建议

如果多人协作：

- A：UI 和交互。
- B：Agent 解析和时间解析。
- C：日历数据层、测试、部署。

如果单人开发：

- 先保证文字版完整闭环。
- 再把文字输入替换为语音入口。
- 最后做视觉和演示增强。
