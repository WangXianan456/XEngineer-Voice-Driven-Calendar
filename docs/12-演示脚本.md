# 演示脚本

## 演示目标

用 3 到 5 分钟展示这个产品不是普通日历，而是能用自然语音管理日程的 Agent。

如果是录制视频，使用 [20-演示视频方案](./20-演示视频方案.md) 作为分镜脚本；本文件保留为现场演示和答辩话术。

## 演示前准备

- 使用 Chrome 浏览器。
- 默认使用「浏览器识别」，不要把「本地 Whisper」作为现场硬依赖。
- 如果麦克风权限不可用，直接使用文字输入框，演示 Agent 闭环不受影响。
- 点击「清空本地数据」或「填充演示数据」把现场状态调到可控状态。
- 打开页面后确认语音入口、Agent 确认区、月历和日程列表都可见。

## 演示话术

### 1. 开场

讲稿：

> 这是一个语音日历 Agent。它解决的是日历管理中最常见的问题：用户知道自己想安排什么，但不想打开复杂表单逐项填写。这里用户可以直接说自然语言，系统会解析时间、标题、提醒和操作类型，并且所有新增、修改、删除都会先进入确认状态机，不会让模型或语音识别结果直接改日历。

展示动作：

- 指向顶部状态，说明默认是浏览器语音识别。
- 指向确认区，说明写操作必须确认。
- 指向月历，说明日程状态不是聊天文本，而是真实日历数据。

### 2. 添加日程

语音指令：

> 明天下午三点开产品评审会，提前十分钟提醒我。

讲稿：

> 这里我用一句自然语言创建日程。系统先把它解析成结构化操作：标题是产品评审会，时间是明天下午三点到四点，提醒是提前十分钟。现在它还没有写入日历，必须等我确认。

展示重点：

- 语音转文字。
- 结构化理解结果。
- 确认后写入日历。
- 日历视图实时更新。

### 3. 查看日程

语音指令：

> 我明天有什么安排？

讲稿：

> 查询操作不会修改状态，所以系统可以直接返回结果。这里它按明天这个时间范围过滤事件，并把结果同步到 Agent 对话区。

展示重点：

- Agent 理解查询范围。
- 返回明天日程摘要。
- 日历区域同步展示。

### 4. 修改日程

语音指令：

> 把产品评审会改到下午四点。

讲稿：

> 这个指令没有再次说日期，但系统会根据匹配到的日程沿用原来的日期，只修改时间。这是日历 Agent 很常见的口语场景：用户说的是“改这个会议的时间”，而不是创建今天的新会议。

展示重点：

- Agent 根据标题匹配已有事件。
- 展示修改前后。
- 用户确认后更新。

### 5. 冲突检测

语音指令：

> 明天下午四点半安排一个设计评审。

如果已有重叠事件，展示：

- 系统提示时间冲突。
- 用户可以确认继续或取消。

讲稿：

> 现在新日程和已有产品评审会重叠，系统不会静默写入，而是在确认卡片里提示冲突。这里我选择取消，说明高风险或异常情况仍由用户决策。

### 6. 删除日程

语音指令：

> 删除明天的产品评审会。

讲稿：

> 删除是高风险操作，所以不会因为一句话直接执行。系统先找到候选日程，展示删除确认。确认后事件被删除，同时最近一次操作可以撤销。

展示重点：

- 删除属于高风险操作。
- 系统必须二次确认。
- 删除后可以撤销。

### 7. 收尾

讲稿：

> 这个项目的关键点不是做一个普通 CRUD 日历，而是把语音、规则解析、LLM 兜底、确认状态机和本地日历状态组合成一个可信 Agent。即使语音、后端或 LLM 不可用，文字输入、本地规则和确认闭环仍然可用。后续可以继续扩展真实日历同步、智能排期和解析质量评测。

补充技术表达：

> 解析质量不是靠感觉判断。项目内置 55 条中文口语评测集，会输出 intent accuracy、slot accuracy、fallback rate 和 unsafe action rate。前端和后端都有 deterministic validator，DeepSeek 返回的 JSON 也必须经过 schema 和语义校验；非法 JSON、非法结构、缺目标删除、非法时间都会降级成追问，不会进入确认卡片。

## 备用演示方案

如果现场语音识别不可用，直接使用文字输入框输入同样的句子。说明语音识别依赖浏览器能力，但 Agent 的日程理解和管理能力仍然完整可用。

## 已回归演示路径

2026-05-31 使用 Chrome headless DevTools 驱动真实页面完成以下路径：

1. 清空本地数据。
2. 输入新增指令并出现待确认操作。
3. 确认新增后 localStorage 写入 1 条日程。
4. 查询明天安排并返回产品评审会。
5. 输入「把产品评审会改到下午四点」，确认卡片显示明天 16:00。
6. 确认修改后事件仍在明天。
7. 新增重叠设计评审，确认卡片提示冲突。
8. 取消冲突新增。
9. 删除明天的产品评审会，出现删除二次确认。
10. 确认删除后事件数为 0。
11. 输入撤销后恢复产品评审会。
12. 页面同时保留「浏览器识别」默认模式和「本地 Whisper」可选开关。
