# 演示脚本

## 演示目标

用 3 到 5 分钟展示这个产品不是普通日历，而是能用自然语音管理日程的 Agent。

## 演示前准备

- 使用 Chrome 浏览器。
- 确认麦克风权限可用。
- 预置 2 条演示日程。
- 打开页面后确认今日、本周和语音入口都可见。

## 演示话术

### 1. 开场

这是一个语音日历 Agent。它解决的是日历管理中最常见的问题：用户知道自己想安排什么，但不想打开复杂表单逐项填写。这里用户可以直接说自然语言，系统会解析时间、事件、提醒，并在写入前让用户确认。

### 2. 添加日程

语音指令：

> 明天下午三点开产品评审会，提前十分钟提醒我。

展示重点：

- 语音转文字。
- 结构化理解结果。
- 确认后写入日历。
- 日历视图实时更新。

### 3. 查看日程

语音指令：

> 我明天有什么安排？

展示重点：

- Agent 理解查询范围。
- 返回明天日程摘要。
- 日历区域同步展示。

### 4. 修改日程

语音指令：

> 把产品评审会改到下午四点。

展示重点：

- Agent 根据标题匹配已有事件。
- 展示修改前后。
- 用户确认后更新。

### 5. 冲突检测

语音指令：

> 明天下午四点半安排一个设计评审。

如果已有重叠事件，展示：

- 系统提示时间冲突。
- 用户可以确认继续或取消。

### 6. 删除日程

语音指令：

> 删除明天的产品评审会。

展示重点：

- 删除属于高风险操作。
- 系统必须二次确认。
- 删除后可以撤销。

### 7. 收尾

这个版本优先保证一天内可上线的核心闭环：语音输入、Agent 理解、日历操作、确认机制和本地持久化。后续可以扩展 Google Calendar、Outlook、多人会议邀请和移动端 PWA。

## 备用演示方案

如果现场语音识别不可用，直接使用文字输入框输入同样的句子。说明语音识别依赖浏览器能力，但 Agent 的日程理解和管理能力仍然完整可用。
