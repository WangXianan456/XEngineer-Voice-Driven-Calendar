## 第一版开发原则

第一版采用：

```text
纯前端主线 + 本地规则解析 + localStorage 持久化 + 浏览器语音能力
```

不把以下能力作为第一版硬依赖：

- 用户登录。
- 云数据库。
- Google Calendar / Outlook 同步。
- 独立后台管理系统。
- 云语音服务。
- 强依赖 AI API。

## 最小上线闭环

第一版必须打通：

```text
语音 / 文字输入
-> Agent 理解
-> 用户确认
-> 日历增删改查
-> 日历视图更新
-> 本地持久化
```

只要这个闭环稳定，就可以形成一个可上线、可演示、可信的语音日历 Agent。
